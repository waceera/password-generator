# password-generator
Create your password with python 💫

How to use?
# For Termux
```Alpine Abuild
INSTALL

pkg upgrade && pkg update

pkg install python

pkg install git
```

```Alpine Abuild
RUN

git clone https://github.com/waceera/password-generator

cd password-generator

python password.py
```

and, done!
